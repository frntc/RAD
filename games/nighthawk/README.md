# NIGHTHAWK

A stealth-fighter flight game in one assembly file: take off, fly a circuit,
strike a target. It is the largest single-file class 1 (3D scene) example.
All geometry is generated by `tools/gen_nighthawk.py`; no third-party assets.

PC check: `tools/examples.sh nighthawk` (autopilot flies; the cockpit camera is
switched in with F1). Controls and mission are described in the header of
`gpu64_demo_nighthawk.a`.
