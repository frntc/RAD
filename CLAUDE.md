# AGENTS.md

This repository is the SDK, examples, games and documentation for gpu64, a
graphics add-on for the Commodore 64 built on the RAD cartridge. It contains
**C64 programs and tools, not the Raspberry Pi firmware.**

Read [docs/ai/AGENTS.md](docs/ai/AGENTS.md): how to write, simulate, and
deploy a program. Work in `examples/`, `games/` or your own folder.

Do not invent opcodes: the v1 API is frozen and documented in `docs/api/`.
